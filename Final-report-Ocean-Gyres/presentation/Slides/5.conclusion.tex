  \section{Conclusion}
 
\textit{Three important conclusions}:
\begin{enumerate}
    \item Both numerical models showed western intensification, explained by Rossby wave propagation. But continuous energy input need dissipation to converge with time. 
    \item Only Munk theory showed a western boundary current, explained by frictional layer, although both numerical models showed return flow.
    \item A larger domain gave same interior meridional velocity, which resulted in a stronger western boundary current.
\end{enumerate}
