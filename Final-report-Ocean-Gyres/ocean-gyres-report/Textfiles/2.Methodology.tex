\section{Methodology}
A model written in Fortran was used that implemented the linear shallow water equations, with a imposed stress described by \autoref{eq:stress}. Otherwise, the code was initialized at rest and used an Euler step for the first step, then a leapfrog scheme on a Arakawa C-grid as presented by \citet{Doos2022}. The code ran for at least 14 days, and was saved for every 12th hour. The code can be observed in \autoref{ap:code}.

The code used a domain depth of \SI{3000}{\meter}, $f_0=\SI{7.27e-5}{\per\second}$ and $\beta=\SI{1.98e-11}{\per\meter\per\second}$. The model used a domain with solid boundaries of the size $L_x=L_y = \SI{7000}{\kilo\meter}$ (dubbed the width for the Pacific Ocean) with $\Delta x=\Delta y = \SI{35}{\kilo\meter}$. VArying the stress was done by using $U_{10} = [\SI{4}{\meter\per\second},\, \SI{5}{\meter\per\second},\, \SI{6}{\meter\per\second}]$, and varying the viscosity was done by $A = [\SI{3e4}{\meter\squared\per\second},\, \SI{1e5}{\meter\squared\per\second},\, \SI{5e5}{\meter\squared\per\second}]$. The harmonic viscosity in the boundary points, assumed zero flow outside the domain.
