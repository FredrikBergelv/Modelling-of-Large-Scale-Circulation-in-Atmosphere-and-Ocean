# Large-Scale Atmosphere and Ocean Modelling

Numerical modelling projects developed as part of the large-scale atmosphere and ocean circulation course at Stockholm University. The repository contains simplified dynamical models and experiments illustrating several fundamental processes in geophysical fluid dynamics and physical oceanography.

## Included Labs
- **Lab 1** — Geostrophic adjustment 
- **Lab 2** — Kelvin waves 
- **Lab 3** — Rossby waves 
- **Lab 4** — Wind-driven ocean circulation (Stommel/Munk)

The projects include numerical simulations in Fortran, visualisation scripts in Python, and short reports for analysing the model behaviour and physical interpretation.
